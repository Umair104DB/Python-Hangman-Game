## Project Overview
A command-line word guessing game built with Python to practice loops, conditions, functions, random selection and input validation.

This repository is part of a practical CodeAlpha project collection. It demonstrates a focused workflow using Python and related tools.

## Why We Built This Project
Small games provide a practical way to learn programming logic. Hangman combines user input, state tracking and conditional outcomes.

## Objectives

- Build an understandable workflow from input to output.
- Practice reusable programming and data-processing concepts.
- Present results in a clear format.
- Document assumptions and limitations.

## Key Features
- Select a random word
- Display hidden letters
- Accept letter guesses
- Track attempts and determine game outcome

## How It Works
Choose a random word, display hidden letters, accept guesses, track attempts, reveal correct letters and detect win or loss conditions.

## Installation
1. Clone the repository:

   ```bash
   git clone https://github.com/Umair104DB/Python-Hangman-Game
   cd Python-Hangman-Game
   ```

2. (Recommended) Create a virtual environment:

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   macOS/Linux:

   ```bash
   source .venv/bin/activate
   ```

3. Install project dependencies:

   ```bash
   pip install -r requirements.txt
   ```
